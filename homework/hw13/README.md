## The segue

One table carries Parts 2 and 3. B1 gives six animals from Viet Nam (sun bear, water buffalo,
pangolin, king cobra, kingfisher, Siamese crocodile) with six columns of data. The student
sorts the columns into the three kinds, then B4 turns each column into a yes/no key question:
4.5's rule *ask about what you can count, measure or see* is discrete, continuous and
categorical data. C2 builds the dichotomous key for the same six animals from that table.
